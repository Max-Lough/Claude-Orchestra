# WORK ORDER — Builder (E2) — WO-12a Order 01 — formatDuration

## MISSION

The fixture library `clikit` can parse duration strings (`src/duration.js`,
`parseDuration`). Add the exact inverse: `formatDuration(ms)`, which renders a
non-negative integer number of milliseconds back into the compact duration
string `parseDuration` accepts.

## BEHAVIOR CONTRACT (exhaustive — implement exactly this, nothing more)

`formatDuration(ms)` returns a `string`.

1. **Validation.** If `ms` is not a number, is `NaN`, is not finite, is not an
   integer, or is negative, throw a `TypeError` whose `message` is exactly:
   `ms must be a non-negative integer`
   (No other error type, no other message. `Number.isInteger` is the integer
   test; booleans, strings and objects are not numbers.)
2. **Zero.** `formatDuration(0) === '0ms'`.
3. **Decomposition.** For `ms > 0`, decompose greedily from the largest unit to
   the smallest over exactly these units and magnitudes:
   `d` = 86400000, `h` = 3600000, `m` = 60000, `s` = 1000, `ms` = 1.
   Each unit takes the whole part of the remaining value; the remainder passes
   to the next unit.
4. **Rendering.** Emit `<count><unit>` for every unit whose count is **not
   zero**, largest unit first, concatenated with **no separator and no
   whitespace**. Units with a zero count are omitted entirely.
5. **Round trip.** For every non-negative integer `n`,
   `parseDuration(formatDuration(n)) === n` must hold.

Worked examples (these are the contract, not suggestions):

| input | output |
|---|---|
| `0` | `0ms` |
| `1` | `1ms` |
| `999` | `999ms` |
| `1000` | `1s` |
| `90000` | `1m30s` |
| `3601000` | `1h1s` |
| `5400000` | `1h30m` |
| `86400000` | `1d` |
| `90061001` | `1d1h1m1s1ms` |
| `172800001` | `2d1ms` |
| `864000000` | `10d` |
