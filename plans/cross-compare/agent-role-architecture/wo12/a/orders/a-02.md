# WORK ORDER — Builder (E2) — WO-12a Order 02 — formatTable options

## MISSION

`formatTable(rows)` in `src/table.js` renders a left-aligned, two-space-
separated text table. Add an optional second parameter, `options`, supporting
per-column alignment and a custom column separator, without changing what
`formatTable(rows)` does today.

## BEHAVIOR CONTRACT (exhaustive — implement exactly this, nothing more)

`formatTable(rows, options)`:

1. **Backward compatibility.** `formatTable(rows)`, `formatTable(rows,
   undefined)`, `formatTable(rows, null)` and `formatTable(rows, {})` all
   produce byte-identical output to today's `formatTable(rows)`.
2. **options validation.** If `options` is present and is neither `undefined`,
   `null`, nor a non-array object, throw `TypeError` with message exactly
   `options must be an object`.
3. **options.separator.** A string placed between adjacent columns. Default
   `'  '` (two spaces). If present and not a string, throw `TypeError` with
   message exactly `separator must be a string`. The empty string is valid.
4. **options.align.** An array whose entries are `'left'` or `'right'`, one per
   column, index-aligned with the columns.
   - If present and not an array, throw `TypeError` with message exactly
     `align must be an array`.
   - A missing entry (index beyond the array, or an `undefined` entry) means
     `'left'`.
   - Any other entry value throws `TypeError` with message exactly
     `invalid alignment: ` followed by `String(value)` — e.g.
     `invalid alignment: center`, `invalid alignment: null`.
   - `'left'` pads the cell on the right to the column width; `'right'` pads it
     on the left.
5. **Everything else is unchanged.** Column width is still the longest
   `String(cell)` in that column; short rows are still padded with empty cells
   to the widest row; rows are still joined with `'\n'`; **trailing whitespace
   is still stripped from every rendered line**; an empty or non-array `rows`
   still renders `''` (before any option validation is worth doing, empty input
   short-circuits to `''`).

Worked examples with `rows = [['id','name'],['1','alpha'],['22','b']]`
(column widths 2 and 5). `\n` shown as a real line break:

- default:
  ```
  id  name
  1   alpha
  22  b
  ```
- `{ separator: ' | ' }`:
  ```
  id | name
  1  | alpha
  22 | b
  ```
- `{ align: ['right','right'] }`:
  ```
  id   name
   1  alpha
  22      b
  ```
- `{ align: ['right'] }` (column 1 defaults to left):
  ```
  id  name
   1  alpha
  22  b
  ```
- `{ align: ['right','right'], separator: '|' }`:
  ```
  id| name
   1|alpha
  22|    b
  ```
