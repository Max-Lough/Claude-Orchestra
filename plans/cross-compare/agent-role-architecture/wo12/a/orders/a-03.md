# WORK ORDER — Builder (E2) — WO-12a Order 03 — relativePath

## MISSION

`src/pathnorm.js` normalizes POSIX-style paths. Add `relativePath(from, to)`,
which computes the relative path that walks from one absolute path to another.

## BEHAVIOR CONTRACT (exhaustive — implement exactly this, nothing more)

`relativePath(from, to)` returns a `string`.

1. **Type check first.** If either argument is not a string, throw `TypeError`
   with message exactly `paths must be strings`.
2. **Absoluteness check second.** A path is absolute when its first character is
   `/` or `\`. If either argument is not absolute (the empty string is not),
   throw `TypeError` with message exactly `paths must be absolute`.
3. **Normalize.** Apply the existing `normalizePath` to both arguments, then
   split each on `/` and drop empty segments, giving two segment lists.
4. **Common prefix.** Drop the longest common leading run of **whole, exactly
   equal** segments from both lists.
5. **Result.** The result is one `..` segment for every segment remaining in
   `from`, followed by every segment remaining in `to`, joined with `/`.
6. **Identity.** If nothing remains on either side, return `'.'`.

Worked examples (these are the contract):

| from | to | result |
|---|---|---|
| `/a/b/c` | `/a/b/c` | `.` |
| `/` | `/` | `.` |
| `/a/b` | `/a/b/c/d` | `c/d` |
| `/` | `/a/b` | `a/b` |
| `/a/b/c` | `/a/b` | `..` |
| `/a/b` | `/` | `../..` |
| `/a/b/c` | `/a/d` | `../../d` |
| `/x/y` | `/p/q` | `../../p/q` |
| `/a//b/./c/` | `/a/x` | `../../x` |
| `\a\b` | `/a/c` | `../c` |
| `/a/b/../b` | `/a/b/z` | `z` |
| `/../a` | `/a/b` | `b` |
| `/ab` | `/abc` | `../abc` |

The last row is the point of rule 4: `ab` and `abc` are different segments, so
nothing is shared.
