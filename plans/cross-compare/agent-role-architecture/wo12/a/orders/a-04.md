# WORK ORDER — Builder (E2) — WO-12a Order 04 — LRUCache inspection API

## MISSION

`src/lru.js` implements `LRUCache` with `get`, `set` and a `size` getter. Add
four inspection methods that let a caller look at the cache **without**
disturbing its recency order.

## BEHAVIOR CONTRACT (exhaustive — implement exactly this, nothing more)

Add these four methods to the `LRUCache` class (they must live on the
prototype, i.e. be declared as class methods, not assigned per instance):

1. **`has(key)`** returns `true` when `key` is present, `false` otherwise.
   It **never** changes recency order and never evicts.
2. **`peek(key)`** returns the stored value when `key` is present and
   `undefined` when it is absent. It **never** changes recency order and never
   evicts. (An entry whose stored value is literally `undefined` is
   indistinguishable from an absent one; that is accepted.)
3. **`delete(key)`** removes the entry and returns `true` when the key was
   present; returns `false` and changes nothing when it was not.
4. **`keys()`** returns a **new** plain `Array` of the keys currently held,
   ordered **least-recently-used first, most-recently-used last**. Mutating the
   returned array must not affect the cache, and two consecutive calls must
   return two different array objects with equal contents.

Recency rules that must continue to hold unchanged:

- `get(key)` on a present key promotes it to most-recently-used.
- `get(key)` on an absent key returns `undefined` and promotes nothing.
- `set(key, value)` inserts or updates and promotes the key to
  most-recently-used, then evicts from the least-recently-used end until
  `size <= capacity`.
- The constructor still throws `TypeError` on a capacity that is not a positive
  integer.

Worked trace (these are the contract). Start `c = new LRUCache(3)`, then
`c.set('a',1); c.set('b',2); c.set('c',3)`:

| call | returns | `keys()` afterwards |
|---|---|---|
| — | — | `['a','b','c']` |
| `c.peek('a')` | `1` | `['a','b','c']` |
| `c.peek('missing')` | `undefined` | `['a','b','c']` |
| `c.has('a')` | `true` | `['a','b','c']` |
| `c.has('zzz')` | `false` | `['a','b','c']` |
| `c.get('a')` | `1` | `['b','c','a']` |
| `c.set('d',4)` | — | `['c','a','d']` |
| `c.set('e',5)` | — | `['a','d','e']` |
| `c.delete('a')` | `true` | `['d','e']` |
| `c.delete('a')` | `false` | `['d','e']` |
