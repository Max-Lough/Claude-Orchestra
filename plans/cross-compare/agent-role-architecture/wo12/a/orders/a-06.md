# WORK ORDER — Builder (E2) — WO-12a Order 06 — stringifyIni

## MISSION

`src/ini.js` parses INI text into a plain object. Add the writer:
`stringifyIni(obj)`, which renders such an object back to INI text that
`parseIni` reads back to the same shape.

## BEHAVIOR CONTRACT (exhaustive — implement exactly this, nothing more)

`stringifyIni(obj)` returns a `string`.

1. **Input validation.** If `obj` is not a plain object — i.e. it is `null`,
   `undefined`, an `Array`, or anything whose `typeof` is not `'object'` —
   throw `TypeError` with message exactly `obj must be a plain object`.
2. **Key order.** Iterate the object's own enumerable string keys in their
   natural (insertion) order, as `Object.keys` gives them.
3. **Value classification, top level.** For each key:
   - a `string`, `number` or `boolean` value is a **scalar**;
   - a non-null, non-Array value whose `typeof` is `'object'` is a **section**;
   - anything else (including `null`, `undefined`, an `Array`, a function)
     throws `TypeError` with message exactly `unsupported value for key: `
     followed by the key name — e.g. `unsupported value for key: a`.
4. **Emission order.** All top-level scalars are emitted first, in key order,
   as `key=value` lines with `String(value)` as the value and **no spaces**
   around the `=`. Then every section is emitted, in key order.
5. **Section rendering.** A section is emitted as a header line `[name]`
   followed by one `key=value` line per entry, in key order. A **blank line**
   precedes the `[name]` header **iff** at least one line has already been
   emitted. A section with no entries renders as a bare header line.
6. **Value classification, inside a section.** Only `string`, `number` and
   `boolean` are allowed.
   - A non-null object or an `Array` throws `TypeError` with message exactly
     `nested sections are not supported`.
   - Anything else (`null`, `undefined`, a function) throws `TypeError` with
     message exactly `unsupported value for key: ` followed by that inner key
     name — e.g. `unsupported value for key: t`.
7. **Terminator.** The result is the emitted lines joined with `'\n'`, plus a
   single trailing `'\n'` when at least one line was emitted. An object with no
   keys renders as `''` (the empty string, no newline).
8. **Round trip.** `parseIni(stringifyIni(obj))` deep-equals `obj` with every
   scalar coerced to its `String(value)` form.

Worked examples (`\n` shown literally):

| input | output |
|---|---|
| `{}` | `''` |
| `{a:'1'}` | `a=1\n` |
| `{a:1, b:true, c:false}` | `a=1\nb=true\nc=false\n` |
| `{b:'2', a:'1'}` | `b=2\na=1\n` |
| `{server:{host:'h'}}` | `[server]\nhost=h\n` |
| `{empty:{}}` | `[empty]\n` |
| `{a:'1', empty:{}}` | `a=1\n\n[empty]\n` |
| `{server:{host:'h'}, top:'1'}` | `top=1\n\n[server]\nhost=h\n` |
| `{top:'1', server:{host:'h',port:8080}, flags:{debug:false}}` | `top=1\n\n[server]\nhost=h\nport=8080\n\n[flags]\ndebug=false\n` |
