# WORK ORDER — Builder (E2) — WO-12a Order 07 — wrapText

## MISSION

Add a new module `src/wrap.js` to the `clikit` library exposing one function,
`wrapText(text, width)`, which greedily wraps text to a fixed column width.

## BEHAVIOR CONTRACT (exhaustive — implement exactly this, nothing more)

`wrapText(text, width)` returns an `Array` of strings (the lines).

1. **text validation.** If `text` is not a string, throw `TypeError` with
   message exactly `text must be a string`.
2. **width validation.** If `width` is not a number, is `NaN`, is not finite,
   is not an integer, or is less than 1, throw `TypeError` with message exactly
   `width must be a positive integer`. Check `text` first, then `width`.
3. **Normalize.** Replace every run of whitespace in `text` (the `\s` class:
   spaces, tabs, newlines, carriage returns) with a single space, then trim the
   leading and trailing space.
4. **Empty.** If the normalized text is the empty string, return `[]`.
5. **Words.** Split the normalized text on single spaces into words.
6. **Hard split, before packing.** Replace every word longer than `width` with
   its consecutive chunks of exactly `width` characters, in order; the final
   chunk of that word may be shorter. Words of length `<= width` are unchanged.
   This produces the **chunk list**.
7. **Greedy pack.** Start the first line with the first chunk. For each
   following chunk: if `currentLine.length + 1 + chunk.length <= width`, append
   `' ' + chunk` to the current line; otherwise finish the current line and
   start a new line with the chunk.
8. **Result.** Return the lines in order. No line is empty, no line has leading
   or trailing whitespace, and no line is longer than `width`.

Worked examples (these are the contract):

| text | width | result |
|---|---|---|
| `''` | 5 | `[]` |
| `'   '` | 5 | `[]` |
| `'x'` | 1 | `['x']` |
| `'a b c'` | 5 | `['a b c']` |
| `'a b c'` | 3 | `['a b','c']` |
| `'aa bb cc dd'` | 5 | `['aa bb','cc dd']` |
| `'the quick brown fox'` | 10 | `['the quick','brown fox']` |
| `'  one   two\nthree\t four  '` | 20 | `['one two three four']` |
| `'abcdefgh'` | 8 | `['abcdefgh']` |
| `'abcdefgh'` | 3 | `['abc','def','gh']` |
| `'aaaa bb'` | 3 | `['aaa','a','bb']` |
| `'xx abcdef yy'` | 2 | `['xx','ab','cd','ef','yy']` |

The `'aaaa bb'` row is rule 6 followed by rule 7: the chunk list is
`['aaa','a','bb']`; `'aaa'` fills the first line, `'aaa a'` would be 5 > 3 so
`'a'` starts a line, and `'a bb'` would be 4 > 3 so `'bb'` starts a line.
