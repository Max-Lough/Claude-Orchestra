# WORK ORDER — Builder (E2) — WO-12a Order 08 — parseArgs

## MISSION

Add a new module `src/args.js` to the `clikit` library exposing one function,
`parseArgs(argv)`, a minimal command-line argument parser.

## BEHAVIOR CONTRACT (exhaustive — implement exactly this, nothing more)

`parseArgs(argv)` returns an object with exactly two properties:
`{ flags, positionals }` — `flags` an object, `positionals` an array of
strings.

1. **Input validation.** If `argv` is not an `Array`, throw `TypeError` with
   message exactly `argv must be an array`. If any element is not a string,
   throw `TypeError` with message exactly `argv entries must be strings`.
2. **Token rules, applied in this exact precedence order.** Walk `argv` left to
   right; for each token, the **first** matching rule wins:
   1. the token is exactly `--` → every **remaining** token (this one excluded)
      is appended to `positionals` verbatim and parsing stops;
   2. the token matches `/^--([A-Za-z0-9][A-Za-z0-9-]*)=([\s\S]*)$/` →
      `flags[name] = value` (a string; the value may be empty, and may itself
      contain `=`);
   3. the token matches `/^--no-([A-Za-z0-9][A-Za-z0-9-]*)$/` →
      `flags[name] = false`, where `name` is what follows `--no-`;
   4. the token matches `/^--([A-Za-z0-9][A-Za-z0-9-]*)$/` →
      `flags[name] = true`;
   5. the token matches `/^-([A-Za-z]+)$/` → **every letter** in the cluster
      gets `flags[letter] = true`;
   6. otherwise → the token is appended to `positionals` verbatim.
3. **Last occurrence wins.** A repeated flag name simply overwrites its earlier
   value, whatever the forms involved.
4. **Positional order** is the order the tokens appeared.
5. Rule 2 outranks rule 3, so `--no-cache=1` sets `flags['no-cache'] = '1'`,
   not `flags.cache = '1'`.

Worked examples (these are the contract):

| argv | flags | positionals |
|---|---|---|
| `[]` | `{}` | `[]` |
| `['--verbose']` | `{verbose:true}` | `[]` |
| `['--dry-run','--v2']` | `{'dry-run':true, v2:true}` | `[]` |
| `['--out=dist']` | `{out:'dist'}` | `[]` |
| `['--out=']` | `{out:''}` | `[]` |
| `['--expr=a=b=c']` | `{expr:'a=b=c'}` | `[]` |
| `['--no-cache']` | `{cache:false}` | `[]` |
| `['--no-cache=1']` | `{'no-cache':'1'}` | `[]` |
| `['-abc']` | `{a:true,b:true,c:true}` | `[]` |
| `['--x','--x=2']` | `{x:'2'}` | `[]` |
| `['--x=2','--no-x']` | `{x:false}` | `[]` |
| `['a','--flag','--','--x','-b','z']` | `{flag:true}` | `['a','--x','-b','z']` |
| `['--','--']` | `{}` | `['--']` |
| `['build','-','---x','-1','--=v','src/a.js']` | `{}` | `['build','-','---x','-1','--=v','src/a.js']` |
| `['build','--out=dist','src','-qz','lib','--no-cache']` | `{out:'dist', q:true, z:true, cache:false}` | `['build','src','lib']` |

The last-but-one row is rule 2.6 in action: `-` alone has no letters, `---x`
and `--=v` do not match any long-flag shape, and `-1` is not a letter cluster —
all four are positionals.
