# WORK ORDER — Interface Artisan (E5), WO-12c casting trial — c-01

## Goal

Build a static, dependency-free, accessible data table with sortable-column
header affordance (markup only — no working sort logic is required or
checked; no browser is available in this harness).

## Output

Exactly one file: **`table.html`** — a standalone, valid HTML document
(`<!DOCTYPE html>` through `</html>`), with its CSS in a single inline
`<style>` block in the `<head>`. No other files.

## Fixed structure (reproduce exactly — acceptance is deterministic on this)

- A `<table id="revenue-table">` with a `<caption>Quarterly Revenue by
  Region</caption>`.
- A `<thead>` row of 5 `<th scope="col">` cells, each carrying
  `aria-sort="none"` and containing one `<button type="button">` whose
  `aria-label` reads `"Sort by Region"`, `"Sort by Q1"`, `"Sort by Q2"`,
  `"Sort by Q3"`, `"Sort by Q4"` respectively (button text may repeat the
  column name).
- A `<tbody>` with exactly 4 rows, each `<tr>` carrying a fixed `id` and
  fixed cell values:

  | row id | Region | Q1 | Q2 | Q3 | Q4 |
  |---|---|---|---|---|---|
  | `row-north` | North | $120,000 | $135,000 | $128,000 | $142,000 |
  | `row-south` | South | $98,000 | $101,000 | $110,000 | $115,000 |
  | `row-east` | East | $87,500 | $92,000 | $95,300 | $99,750 |
  | `row-west` | West | $150,200 | $148,900 | $155,000 | $160,400 |

## Fixed palette (hex — reproduce exactly)

- Header cells (`#revenue-table thead th`): text `#ffffff` on background
  `#1d4ed8`.
- Body cells (`#revenue-table tbody td`): text `#111827` on background
  `#ffffff`.

Declare each pair as `color` + `background-color` (or `background`) on the
named CSS rule so the mechanical check can find both properties together.

## Constraints (do not)

- Do **not** load any external CSS or JS (`<link rel="stylesheet">` or
  `<script src=...>` are both forbidden) — everything lives in `table.html`.
- Do **not** use inline event-handler attributes (`onclick=`, `onmouseover=`,
  etc.) anywhere.
- Do **not** include any `http://` or `https://` literal URL anywhere in the
  file.
- Do **not** implement a working sort (no browser exists to exercise it in
  this harness) — the `aria-sort`/button pair is the affordance; leave it
  inert or wire it with `addEventListener` in an inline `<script>` if you
  wish, but a working sort is neither required nor checked.

## Mechanical acceptance checks (by name — run via `check.js`)

`node c/check.js --order c-01 --file table.html` runs:

1. `well-formedness (tag-balance)`
2. `no external <script src>`, `no external <link rel="stylesheet">`,
   `no inline event-handler attributes (on*=)`, `no http(s):// literal URLs`
3. the 12 `requiredStructure` checks named in `c/checks/c-01.json`
   (table id, caption, the 5 `aria-sort`/aria-label pairs, the 4 row ids,
   the 4 Q4 values)
4. `contrast: table header text on header background`,
   `contrast: table body text on body background` (both ≥ 4.5:1)

## Budget

15 minutes.
