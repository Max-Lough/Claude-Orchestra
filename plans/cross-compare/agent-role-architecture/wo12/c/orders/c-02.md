# WORK ORDER — Interface Artisan (E5), WO-12c casting trial — c-02

## Goal

Build a static, dependency-free card grid that lays out 1 column on narrow
viewports, 2 columns at medium width, and 3 columns at wide width. No
browser is available in this harness, so the responsive behavior is checked
mechanically (the CSS rules must exist, exactly as specified below), not by
rendering.

## Output

Exactly one file: **`cards.html`** — a standalone, valid HTML document, with
its CSS in a single inline `<style>` block in the `<head>`. No other files.

## Fixed structure (reproduce exactly)

- A container `<div class="card-grid" id="card-grid" role="list">`.
- Exactly 3 `<article class="card" id="card-N" role="listitem">` children
  (`N` = 1, 2, 3), each containing one `<h2>` and one `<p>` and one
  `<button type="button">`:

  | id | h2 | p | button aria-label |
  |---|---|---|---|
  | `card-1` | Starter Plan Overview | Everything you need to launch your first project, with community support included. | Learn more about the Starter plan |
  | `card-2` | Growth Plan Overview | Add automated backups, priority support, and team collaboration tools. | Learn more about the Growth plan |
  | `card-3` | Scale Plan Overview | Unlimited projects, dedicated infrastructure, and a named support engineer. | Learn more about the Scale plan |

  Each button's visible text is "Learn more"; the `aria-label` above is the
  full accessible name.

## Fixed palette and layout (hex + breakpoints — reproduce exactly)

- `.card { color: #111827; background-color: #f3f4f6; }` (title/base text
  on card background).
- `.card p { color: #374151; background-color: #f3f4f6; }` (body text on
  card background).
- `.card-grid { display: grid; grid-template-columns: 1fr; ... }` (base,
  single column).
- `@media (min-width: 640px) { .card-grid { grid-template-columns:
  repeat(2, 1fr); } }` (2 columns).
- `@media (min-width: 1024px) { .card-grid { grid-template-columns:
  repeat(3, 1fr); } }` (3 columns).

## Constraints (do not)

- Do **not** load any external CSS or JS.
- Do **not** use inline event-handler attributes.
- Do **not** include any `http://` or `https://` literal URL.
- Do **not** use a CSS framework or a `<link>` to any grid library — the
  grid is hand-written CSS Grid, inline.

## Mechanical acceptance checks (by name)

`node c/check.js --order c-02 --file cards.html` runs:

1. `well-formedness (tag-balance)`
2. the 4 forbidden-content checks
3. the 11 `requiredStructure` checks named in `c/checks/c-02.json`
   (container role, the 3 cards' ids/roles/copy/aria-labels, the base and
   the two breakpoint `grid-template-columns` rules)
4. `contrast: card title text on card background`,
   `contrast: card body text on card background` (both ≥ 4.5:1)

15 minutes.
