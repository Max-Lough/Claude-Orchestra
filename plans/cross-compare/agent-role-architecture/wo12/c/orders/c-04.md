# WORK ORDER — Interface Artisan (E5), WO-12c casting trial — c-04

## Goal

Build a static, dependency-free tabbed panel with correct ARIA
`tablist`/`tab`/`tabpanel` roles and correct initial state. No browser is
available in this harness; whether clicking actually switches tabs is not
checked (no working JS is required), but the static ARIA wiring and
`hidden` state on the inactive panels is.

## Output

Exactly one file: **`tabs.html`** — a standalone, valid HTML document, with
its CSS in a single inline `<style>` block in the `<head>`. No other files.

## Fixed structure (reproduce exactly)

```html
<div class="tabs" id="settings-tabs">
  <div role="tablist" aria-label="Settings sections">
    <button type="button" role="tab" id="tab-profile" aria-selected="true" aria-controls="panel-profile">Profile</button>
    <button type="button" role="tab" id="tab-billing" aria-selected="false" aria-controls="panel-billing" tabindex="-1">Billing</button>
    <button type="button" role="tab" id="tab-security" aria-selected="false" aria-controls="panel-security" tabindex="-1">Security</button>
  </div>
  <div role="tabpanel" id="panel-profile" aria-labelledby="tab-profile">
    <p>Update your name, photo, and contact details.</p>
  </div>
  <div role="tabpanel" id="panel-billing" aria-labelledby="tab-billing" hidden>
    <p>Manage your payment method and view past invoices.</p>
  </div>
  <div role="tabpanel" id="panel-security" aria-labelledby="tab-security" hidden>
    <p>Change your password and review active sessions.</p>
  </div>
</div>
```

Reproduce this exactly, including attribute order (the mechanical check
matches literal markup) and the `hidden` attribute on the two non-active
panels only.

## Fixed palette (hex — reproduce exactly)

- `[role="tab"][aria-selected="true"] { color: #ffffff; background-color:
  #1d4ed8; }`
- `[role="tabpanel"] { color: #111827; background-color: #ffffff; }`

## Constraints (do not)

- Do **not** load any external CSS or JS.
- Do **not** use inline event-handler attributes.
- Do **not** include any `http://` or `https://` literal URL.
- Do **not** mark more than one tab `aria-selected="true"`, and do **not**
  leave the initially-active panel (`panel-profile`) `hidden`.

## Mechanical acceptance checks (by name)

`node c/check.js --order c-04 --file tabs.html` runs:

1. `well-formedness (tag-balance)`
2. the 4 forbidden-content checks
3. the 9 `requiredStructure` checks named in `c/checks/c-04.json` (tablist,
   the 3 tab buttons' full role/state/controls wiring, the 3 tabpanels'
   role/labelledby/hidden state, and exact counts of `role="tab"` and
   `role="tabpanel"`)
4. `contrast: selected-tab text on selected-tab background`,
   `contrast: tabpanel body text on tabpanel background` (both ≥ 4.5:1)

15 minutes.
