# WORK ORDER — Interface Artisan (E5), WO-12c casting trial — c-05

## Goal

Build a static, dependency-free set of 3 notification banners (info, warn,
error), each meeting WCAG-AA contrast (≥ 4.5:1) for its declared text/
background pair, with the ARIA role matching its urgency.

## Output

Exactly one file: **`banners.html`** — a standalone, valid HTML document,
with its CSS in a single inline `<style>` block in the `<head>`. No other
files.

## Fixed structure (reproduce exactly)

```html
<div class="banner banner-info" id="banner-info" role="status">
  <p>Your changes have been saved successfully.</p>
</div>
<div class="banner banner-warn" id="banner-warn" role="status">
  <p>Your session will expire in 5 minutes.</p>
</div>
<div class="banner banner-error" id="banner-error" role="alert">
  <p>Unable to save changes. Please try again.</p>
</div>
```

Note the role split: info and warn are `role="status"` (polite,
non-interruptive); error is `role="alert"` (assertive) — this is the fixed
spec, not a free choice.

## Fixed palette (hex — reproduce exactly)

- `.banner-info { color: #14532d; background-color: #f0fdf4; }`
- `.banner-warn { color: #92400e; background-color: #fffbeb; }`
- `.banner-error { color: #7f1d1d; background-color: #fee2e2; }`

## Constraints (do not)

- Do **not** load any external CSS or JS.
- Do **not** use inline event-handler attributes.
- Do **not** include any `http://` or `https://` literal URL.
- Do **not** substitute any other hex values for the palette above, even
  ones that "look" similarly accessible — the mechanical check computes the
  ratio from whatever is actually declared, so a plausible-looking
  substitute that fails 4.5:1 will fail the check, and a substitute that
  passes but isn't the declared palette will fail structure review even if
  it happens to pass contrast.

## Mechanical acceptance checks (by name)

`node c/check.js --order c-05 --file banners.html` runs:

1. `well-formedness (tag-balance)`
2. the 4 forbidden-content checks
3. the 6 `requiredStructure` checks named in `c/checks/c-05.json` (each
   banner's id/class/role, each banner's fixed copy)
4. `contrast: info banner text on info background`,
   `contrast: warn banner text on warn background`,
   `contrast: error banner text on error background` (all three ≥ 4.5:1)

## Budget

15 minutes.
