# WORK ORDER — Interface Artisan (E5), WO-12c casting trial — c-06

## Goal

Build a static, dependency-free pricing table with a visually highlighted
"featured" plan row that still meets WCAG-AA contrast on its inverted
color scheme.

## Output

Exactly one file: **`pricing.html`** — a standalone, valid HTML document,
with its CSS in a single inline `<style>` block in the `<head>`. No other
files.

## Fixed structure (reproduce exactly)

- A `<table id="pricing-table">` with `<caption>Plan Pricing
  Comparison</caption>`.
- A `<thead>` row of exactly 4 `<th scope="col">` cells: Plan, Monthly
  Price, Storage, Support.
- A `<tbody>` with exactly 3 rows, each a `<tr id="...">` with a `<th
  scope="row">` plan name followed by 3 `<td>` cells:

  | row id | plan (th scope=row) | price | storage | support | extra class |
  |---|---|---|---|---|---|
  | `plan-starter` | Starter | $9 | 10 GB | Email | — |
  | `plan-growth` | Growth | $29 | 100 GB | Priority email | `class="featured"` |
  | `plan-scale` | Scale | $79 | 1 TB | 24/7 phone | — |

## Fixed palette (hex — reproduce exactly)

- `#pricing-table { color: #111827; background-color: #ffffff; }` (base
  text on base background, all non-featured rows).
- `#pricing-table .featured { color: #ffffff; background-color: #111827;
  }` (the Growth row's inverted highlight).

## Constraints (do not)

- Do **not** load any external CSS or JS.
- Do **not** use inline event-handler attributes.
- Do **not** include any `http://` or `https://` literal URL anywhere in
  the file — including as a "starts at" pricing-page link; there is none in
  this order.
- Do **not** apply the `featured` class to any row but `plan-growth`.

## Mechanical acceptance checks (by name)

`node c/check.js --order c-06 --file pricing.html` runs:

1. `well-formedness (tag-balance)`
2. the 4 forbidden-content checks
3. the 7 `requiredStructure` checks named in `c/checks/c-06.json` (table
   id, caption, the 4 `scope="col"` headers, the 3 `scope="row"` headers,
   each row's id/class/price)
4. `contrast: base table text on table background`,
   `contrast: featured row text on featured row background` (both ≥
   4.5:1)

## Budget

15 minutes.
