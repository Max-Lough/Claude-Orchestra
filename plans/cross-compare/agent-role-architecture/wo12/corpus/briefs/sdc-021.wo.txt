Change the guard's default behavior for an undetermined model from enforcing
to standing down. Today, when the transcript has no assistant entry yet —
notably a brand-new session's very first turn — the guard treats the

cost — a single unenforced opening turn — before hard enforcement engages as
soon as the model appears in the transcript, and confirm the existing
delegation instructions already cover that gap. Update the docs describing
mode detection and troubleshooting to match the corrected default.
