Commit subject:      Make the guard model-aware: enforce only for director models

ORDER:
Make the guard hook read the session's model before deciding whether to deny
a tool call. Today it blocks edit, write, shell, and search tools for every
main-session call regardless of which model is running it, so a session
already told to go dormant and behave like a plain session is denied every
edit anyway, because instructions alone cannot unblock a hook. Read the
latest non-sidechain assistant model from the session transcript with a
fixed-cost tail read, and enforce only when that model is a director model;
any other model stands the guard down entirely. Resolve an undetermined
model to enforce, so the harness never silently disappears for an actual
director session. Read the latest turn so a mid-session model switch is
honored immediately, and skip sidechain entries so a finished scout run
under a different model cannot be mistaken for the session's own model.
Update the docs to describe the new behavior.

Audit the diff between base and head against the order above: correctness,
