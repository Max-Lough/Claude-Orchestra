This change makes the guard hook read the session's own model first, and it
decides whether to deny a tool call. Enforcement now applies to director

partial state in between the two. An undetermined model still resolves to

the latest turn alone means a mid-session model switch gets honored right
away rather than through a stale cached value, and detection runs solely on
the would-deny path, so an allowed call pays nothing extra. The docs then
get updated to describe the new behavior in full.
