ORDER AS ISSUED

Add continuous integration that runs the review-lane suite
(`node tests/review-lane.test.js`) on Linux, Windows, and macOS across
Node 20, 22 and 24, for every push and every pull request. Windows is the
reason this exists: every field failure in this lane has happened there,
the suite exited 0 there even with failing cases through two rounds of
real failures, and no session working on this repo has a Windows machine
to check by hand. Fix, in the same change, the two Windows facts the
matrix forces into the open — the runner cannot CreateProcess a `.js`
file, so the tests hand it a `.cmd` shim; and `kill('SIGTERM')` there is
TerminateProcess, so the Windows expectation is the SIGKILL one (the
orphan survives and the next run's sweep reclaims it). Also give
`helperSiblings` an environment form, `ORCHESTRA_CODEX_HELPER_SIBLINGS`,
for symmetry with every other codex setting.

Constraints on the CI job:

- Every leg of the matrix must run to completion and report its own
  result. A failure on one platform or Node version must never cancel or
  hide the others — the entire point of the matrix is to see WHICH
  platforms disagree, so a single red leg may not deprive the run of the
  other legs' answers.
- No build, no bundle, no publish step: the harness ships by `git pull`
  plus `node install.js`.
- No linter or formatter job, and no new dependency: this repository has
  zero dependencies and no package.json, and the job must need nothing
  but plain node and plain git.
