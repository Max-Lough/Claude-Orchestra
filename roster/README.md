# roster/ — archived

This directory no longer holds active agent profiles. The active roster
lives in `agents/` and `packs/codex/agents/`; those are the files the
installer stamps and the frontmatter linter checks.

Everything remaining here is dated historical evidence from the 2026-08/09
Orchestra 2.0 build and shakedown — plans, orders, verdicts, reports, and
oracle reviews for the role architecture, readiness repairs, and WO-14b
activation work. None of it is installed, linted, or otherwise live; it is
kept for the record.

For the reverse-port that retired Orchestra 2.0 (including the twelve
active role profiles and `roster/lint.js` that used to live alongside these
files), see `plans/port-3.0/`.
